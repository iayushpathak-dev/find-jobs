## Flipkart Front End Engineer UI2/SDE-2 (Roundz, Apr 2025, REJECTED)
- R1 machine coding + review (120 min, easy): small app in plain HTML/CSS/JS (question shared in advance); live review of naming, folder structure, modularity.
- R2 PS-DS (60 min): run array of promise functions in parallel, then sequentially without async/await (recursion); LC 690 Employee Importance variant (referral bonus on n-ary tree); React reconciliation + virtual DOM; LC 1379 variant on n-ary tree; curried sum(2)(3)(4)() = 9.
- R3 UI tech (60 min): Promise.all from scratch with edge cases; memoization, debounce, throttle, this; flexbox center; web vitals, critical rendering path, lazy loading.
- R4 product sense (45 min, hardest): design a 2-player game with multiple fighters, P0/P1/P2 features; then booking systems, photo sharing, MVP trade-offs.
- R5 HM (60 min): past work, mentoring, conflict; web security; perf tuning; integrate Stripe-like payment gateway into Flipkart architecture.
- Tips: webpack + hot reload, modular folders; trees/DFS/BFS/recursion; closures, this, prototypes; practise product sense + MVP prioritization; STAR stories; know one payment-gateway flow deeply. Lesson: product sense rounds are not only for PMs.
