## LinkedIn Senior Front End Engineer IC3, Bangalore (Roundz, Aug 2025, 7 yrs, REJECTED)
- R1 screen: JS output (hoisting, scope, closures, coercion), prototypes, events, optimization; replicate a UI widget from an image with semantic HTML/CSS/JS + a11y.
- R2 system design: autocomplete widget design then implement (debounce, network, rendering).
- R3 pragmatic UI: calculator (UI, logic, state); MVC vs MVVM; pros/cons of widgets in iframe (security, isolation, postMessage).
- R4 DSA (hard): is DOM node A a child of node B (better: walk child -> parent); Maximum Subarray (Kadane).
- R5 JS: implement clearAllTimeout(); infinite scroll component.
- R6 product sense: app you love and why; A/B test design + metrics.
- R7 HM: project, team, motivation, conflict, deadlines.
- Why rejected: needed hints on DOM question; weak senior signal in system design.
- Tips: JS internals + production UI over LeetCode for screen; explain trade-offs; fewer hints; product thinking.

## Amazon Frontend Engineer I, India (LeetCode, REJECTED)
- Mettl OA: 1 coding + MCQs (DSA, OOP, networks, DBMS, SQL, testing). Frontend assignment.
- R1 DSA: triplet summing to 0 in BST (inorder -> 3Sum); row with most 1s in row-sorted matrix (two pointer).
- R2: recreate a UI live with HTML/CSS.
- Takeaways: DSA matters even for frontend at Amazon; practise plain HTML/CSS; don't lean on Copilot in live coding.
