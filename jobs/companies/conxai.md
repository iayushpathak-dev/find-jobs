## Ayush ke liye
- Process fast ho sakta hai (4 din, 2 rounds). Pehla round **CEO** ka hoga: company aur product ki baat. Unki website aur product (construction AI, site photos/video analysis) padh ke jao.
- Technical round **CTO** lega: architecture, security, "kyun ye choose kiya" type sawal. Tumhare BFF, Partner Studio auth, aur liveness check (TF.js + computer vision!) ke decisions yahan perfect fit hain.
- Liveness check project zaroor bolna: browser mein computer vision, ye unke domain ke paas hai.
- Job post: React + TS, Zustand, React Query, MUI, Jest/RTL, Webpack. Sab tumhare paas hai.
- Red flag reports: founders ka alag feedback, attrition. Offer aaye to team size aur kaun manager hoga ye poochna.
